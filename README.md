# Real-time-IoT-Enabled-greenhouse-for-Precision-Agriculture-
Real-Time IoT Enabled Greenhouse for Precision Agriculture using ESP32, DHT11, soil moisture sensor, LCD, and ThingSpeak cloud monitoring.


## Project Overview
This project uses the Internet of Things (IoT) to monitor greenhouse environmental conditions in real time. An ESP32 collects temperature, humidity, and soil moisture data from sensors and displays the readings on an LCD. The data is also uploaded to ThingSpeak for cloud-based monitoring.

## Objectives
- Monitor temperature and humidity inside a greenhouse.
- Measure soil moisture levels.
- Display sensor readings on an LCD.
- Upload sensor data to the ThingSpeak cloud platform.
- Demonstrate an IoT-based approach to precision agriculture.

## Hardware Components
- ESP32 Dev Module V1
- DHT11 temperature and humidity sensor
- Soil moisture sensor
- 16×2 LCD with I2C module
- Relay module and mini DC water pump
- Connecting wires and power supply

## Software and Technologies
- Arduino IDE
- Embedded C for ESP32
- ThingSpeak IoT cloud platform

## Working Principle
The DHT11 measures temperature and humidity, while the soil moisture sensor measures the moisture level in the soil. The ESP32 processes the sensor readings, displays them on the LCD, and sends the data to ThingSpeak over Wi-Fi. A relay-controlled mini water pump is included as part of the irrigation demonstration.

## Applications
- Greenhouse monitoring
- Smart agriculture
- Soil moisture monitoring
- IoT-based environmental monitoring

## Future Enhancements
- Integrate weather forecast data.
- Add alerts for abnormal environmental conditions.
- Analyse historical sensor data to improve irrigation decisions.
